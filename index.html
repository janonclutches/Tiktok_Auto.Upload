TikTok Minecraft Video Bot

This project is a personal automation tool designed to create short Minecraft-style videos and upload them to TikTok using the official TikTok Content Posting API after user authorization.

Privacy Policy

Effective Date: May 18, 2026

This application uses TikTok OAuth only to allow the authorized user to upload videos.

The app may receive and store a TikTok access token, refresh token, open ID, and granted scopes. These are used exclusively for uploading videos through TikTok’s API.

The app does not sell personal data and does not use tracking cookies.

Users may revoke access at any time through their TikTok account settings.
